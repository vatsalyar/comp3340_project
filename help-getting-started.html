How to Update Content

1) Update Products & Pricing: Log in to the Admin Dashboard to add, edit, or remove products in the catalog. You can easily update product names, categories, fitment compatibility, and prices directly through the admin interface, no coding required!

2) Update Product Images: Upload your new image files directly to the assets/images/ folder on the server. Then, go to the Admin Dashboard, edit the corresponding product, and update its image_path field to match the new file location (for example: assets/images/new-brake-pad.jpg).

3) Update Video & Audio Media: Place your new video or audio files into the assets/media/ folder. To display them, open the relevant page file (such as index.php) and update the filename within the media tags to match your new file.

4) Maintainability: Please ensure all existing code comments and context-sensitive help links remain intact when making administrative changes to the site layout.
